## 🧩 About

**Warcraft 3 Companion** is a curated list of Warcraft 3 open-source tools:

- **Overlays** — on-screen helpers, layout notes, resource tracker, unit tracker
- **Quality-of-Life Helpers** — custom hotkeys, inventory manager, overlay notes
- **Research Notes** — campaign layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Gameplay Helpers
- Resource Tracker — monitor gold, lumber, and supply in real time
- Unit Tracker — display enemy and allied unit positions on the map
- Custom Hotkeys — rebind abilities and commands for convenience
- Game Speed Control — adjust game speed for study (0.5x to 2x)

### 🎨 Interface & Cosmetics
- Inventory Manager — organize items and equipment
- Custom UI Skins — change interface colors and layouts
- Health Bars Overlay — improved visibility of unit health

### 🗺️ Map & Strategy
- Map Reveal — reveal fog of war for single-player exploration
- Build Order Notes — save and review build orders
- Replay Analysis — record and review game sessions
